## 此次发现并修正的其他问题

- 清单脚本对缺失输入路径静默略过：改为报错；隐藏项提供明确提示和纳入开关；同名文件显示完整路径。
- 无法识别的逐字稿格式会输出零段骨架：改为报错；未归入发言的行发出核对提示；不再删除发言内以“生成时间”开头的内容。
- 单一场景阈值与滚动检测经验存在落差：入口改为结合强切换、低阈值检测与区间覆盖核验。
- 安装说明缺少外部依赖边界：补充完整下载、其他 Agent 调用、模型/工具/权限前提与校验命令。

## 可复查验证与边界

`python3 -m unittest discover -s tests -v` 包含 12 项离线测试，覆盖上述脚本行为；腾讯 HTTP 失败测试为模拟子进程返回值，不代表真实腾讯服务端已验证。

`python3 scripts/verify_package.py` 按 SHA256SUMS 核对发布文件。另核对 Markdown 相对文件链接、语法、完整目录以及宪法原文未变。发布后再次匿名下载固定提交 ZIP，运行相同包校验与测试，结果由发布会话汇报。

没有在此次核验中处理一场真实会议，没有执行完整 ASR、视觉逐帧理解、外语逐字翻译或在线腾讯双流下载；不能由这些离线检查推导所有 Agent 均能即装即用或输出无遗漏。辅助脚本支持有限平台格式，解析结果仍须逐段与原文核对；符号链接目录、容器内附件和用户另行指定材料须补入清单。模型、工具与资料权限符合 README 前提的 Agent 才能继续执行相应流程。
